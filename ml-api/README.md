# CultivAIQ ML API (Mock)

This service provides mock responses for predictions and recommendations.

## Run
1. Create a virtual environment.
2. Install deps: `pip install -r requirements.txt`
3. Start: `python app.py`

Default URL: `http://localhost:7000`

## Endpoints
- GET `/health`
- POST `/predict`
- POST `/crop-recommendation`
- POST `/chat`
